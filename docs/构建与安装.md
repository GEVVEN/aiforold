# 构建与安装（含 Windows 自签）

## 0. 先说清楚前提

iOS 的 `.ipa` **必须由 macOS 上的 Xcode 编译并签名**，Windows 无法直接产出可安装的 ipa。所以拿到 ipa 有两条现实路径：

| 路径 | 需要什么 | 适合谁 | 有效期 |
| --- | --- | --- | --- |
| **A. GitHub Actions 云打包 → Windows 自签** | GitHub 账号 + Windows 电脑 + iPhone 数据线 | 没有 Mac 的绝大多数人 | 自签 7 天（AltStore 可自动续） |
| **B. Mac + Xcode** | 一台 Mac | 有 Mac 或能借到 | 同上；付费账号可 1 年 |

下面两条都按「从零开始」写。

---

## 路线 A：GitHub Actions 云打包 + Windows 自签

### A1. 上传代码

在 GitHub 新建一个仓库（公开/私有都行，私有仓库的 Actions 也有每月免费额度），把本目录整体推上去：

```bash
cd AIAssistant
git init
git add .
git commit -m "AI 助手 iOS 客户端"
git branch -M main
git remote add origin https://github.com/你的用户名/你的仓库.git
git push -u origin main
```

> 也可以直接在 GitHub 网页上 **Add file → Upload files** 把整个文件夹拖进去。注意要保留 `.github/workflows/build-ipa.yml`（有的解压工具会漏掉点开头的目录）。

### A2. 触发云打包

1. 打开仓库 → **Actions** 标签页；
2. 左侧选 **Build unsigned IPA** → 右侧 **Run workflow** → 绿色按钮；
3. 等 3–5 分钟（第一次会慢一点，要下 Xcode 环境）；
4. 跑完后点进这次运行，页面底部 **Artifacts** 下载 `AIAssistant-unsigned-ipa.zip`，解压得到 `AIAssistant-unsigned.ipa`。

如果构建失败，同一次运行里还有一个 `build-log` 产物，里面有 `xcodebuild` 的完整报错。

### A3. Windows 上签名并安装（Sideloadly，推荐）

1. 电脑装好 **iTunes（微软商店版或官网版都可以，装它是为了 iOS 设备驱动）**，然后用数据线把 iPhone 连上，手机上点「信任此电脑」。
2. 下载并安装 [Sideloadly](https://sideloadly.io/)。
3. 打开 Sideloadly：
   - **IPA** 选刚才的 `AIAssistant-unsigned.ipa`；
   - **Apple ID** 填你的 Apple ID（免费账号即可）；
   - 设备会自动识别出来；
   - 点 **Start**，会提示输入 Apple ID 密码（密码只用于本地向 Apple 换取签名证书，不经过第三方服务器）。
4. 等进度条走完，手机上会出现「AI 助手」图标。
5. 首次打开会弹「未受信任的开发者」，去 iPhone：
   **设置 → 通用 → VPN 与设备管理（iOS 12 叫「描述文件与设备管理」）→ 开发者 App → 信任你的 Apple ID**。
6. 回到桌面打开 App 即可。

> 如果安装时报 `bundle identifier` 冲突，用 Sideloadly 里的 **Change Bundle ID** 改一下（例如加个 `.me`）。

### A4. AltStore 路线（能自动续签）

1. 电脑装 AltServer（[altstore.io](https://altstore.io/)），iPhone 装 AltStore（AltServer 会通过数据线帮你装）。
2. 把 ipa 传到 iPhone（AirDrop / 文件 App / 网盘）。
3. 在 AltStore 里点 **+** 选这个 ipa 安装。
4. AltStore 会在后台保持续签，7 天到期自动重新签名（需要 iPhone 和运行 AltServer 的电脑在同一 Wi-Fi）。

### A5. 免费 Apple ID 的三个限制（必须知道）

1. 签名 **7 天**过期，过期后 App 打不开，需要重新签一次；
2. 一个 Apple ID 最多同时签 **3 个**自签 App；
3. 部分账号会要求先在 [appleid.apple.com](https://appleid.apple.com) 开启双重认证。

## 路线 B：Mac + Xcode

1. 安装 **Xcode 15.x**（推荐 15.4）。
   - Xcode 16 也还能把部署目标设成 iOS 12，但官方口径已改为 iOS 13 起，用 15.x 最省心。
2. 双击 `AIAssistant.xcodeproj` 打开工程。
3. 选中左侧项目 → **TARGETS: AIAssistant → Signing & Capabilities**：
   - 勾上 **Automatically manage signing**；
   - **Team** 选你的 Apple ID；
   - **Bundle Identifier** 改成全球唯一的，例如 `com.yourname.aiassistant`。
4. 顶部设备选你的 iPhone（首次要等 Xcode 处理证书），按 **⌘R** 运行。
5. 导出 ipa：**Product → Archive → Distribute App → Ad Hoc / Development → Export**，得到 ipa 后用 Apple Configurator、爱思助手或 Sideloadly 装到手机。

命令行编译（等价于 CI 做的事）：

```bash
xcodebuild -project AIAssistant.xcodeproj \
           -scheme AIAssistant \
           -configuration Release \
           -destination 'generic/platform=iOS' \
           -derivedDataPath build \
           CODE_SIGNING_ALLOWED=NO CODE_SIGNING_REQUIRED=NO CODE_SIGN_IDENTITY="" \
           build
```

> ⚠️ 不要写成 `-target AIAssistant -derivedDataPath build`：`xcodebuild` 会直接报错
> 「在指定 -derivedDataPath 时，必须使用 -scheme、-testProductsPath 或 -xctestrun」。
> 用 `-target` 时就不能指定 `-derivedDataPath`（产物会落在默认 DerivedData 里，用
> `xcodebuild -showBuildSettings | grep BUILT_PRODUCTS_DIR` 找）。云打包脚本用的是 `-scheme`。
> 这也意味着 **共享 scheme 必须存在**：`AIAssistant.xcodeproj/xcshareddata/xcschemes/AIAssistant.xcscheme`，
> 用 `python3 tools/generate_pbxproj.py` 会一并生成；若在 Xcode 里手动删过，重跑脚本即可。

## 常见问题

**Q：Actions 里构建步骤报「在指定 -derivedDataPath 时，必须使用 -scheme、-testProductsPath 或 -xctestrun」？**
A：旧的 workflow 里用了 `-target` + `-derivedDataPath`，xcodebuild 不接受这个组合（本仓库已修）。用最新的 `.github/workflows/build-ipa.yml` 重新提交一次即可；原理见上面的命令行编译说明。

**Q：Actions 报 `xcodebuild -list` 里没有 AIAssistant scheme？**
A：共享 scheme 丢了。本地跑 `python3 tools/generate_pbxproj.py` 重新生成后提交（会同时重建 `xcshareddata/xcschemes/AIAssistant.xcscheme`）。

**Q：装好后点图标闪退？**
A：多半是部署目标不对（比如设备是 iOS 12，但包是按 iOS 13 部署目标编出来的）。确认 `project.pbxproj` 里 `IPHONEOS_DEPLOYMENT_TARGET = 12.0;`；云打包用的就是这套配置。

**Q：Xcode 提示 "Untrusted Developer" 或打不开？**
A：按 A3 第 5 步去「描述文件与设备管理」里信任证书。

**Q：改过源码后 Xcode 里看不到新文件？**
A：工程文件是脚本生成的，新增 / 删除 `.swift` 之后要重跑：

```bash
python3 tools/generate_pbxproj.py
python3 tools/generate_pbxproj.py --check   # 校验工程与源码一致
python3 tools/check_ios12.py                # 静态自检
```

**Q：想让 App 名字或图标不一样？**
A：名字改 `AIAssistant/Info.plist` 的 `CFBundleDisplayName`；图标改 `tools/make_icon.py` 顶部两个颜色常量后重跑脚本。

**Q：想上架 App Store？**
A：需要先做三件事：① 删掉 `Info.plist` 里的 `NSAppTransportSecurity / NSAllowsArbitraryLoads`（或收紧到你的域名）；② 把 App 名称、图标、隐私说明准备齐；③ 使用付费开发者账号。注意：允许用户自由填入任意第三方 API Key 的客户端，上架审核存在较大不确定性，个人自用建议走自签。
